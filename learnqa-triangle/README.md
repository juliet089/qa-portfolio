# QA Portfolio — Тестирование playground.learnqa.ru/puzzle/triangle

Учебный проект по мануальному тестированию: тестирование формы определения типа треугольника по трём сторонам на тренажёре [LearnQA Playground](https://playground.learnqa.ru/puzzle/triangle).

## Что сделано

- Функциональное тестирование формы (позитивные и негативные сценарии)
- Применение техник тест-дизайна: классы эквивалентности, граничные значения
- Найдено и задокументировано 5 дефектов (3 официальных бага площадки + 2 самостоятельные находки)
- Оформлены баг-репорты с указанием Severity/Priority и обоснованием

## Структура репозитория

- `bug-reports.md` — найденные дефекты
- `Test-cases.md` — набор тест-кейсов

## Инструменты

Ручное тестирование, анализ через DevTools браузера.

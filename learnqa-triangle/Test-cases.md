## TC1: Empty fields

**Summary:** Программа не принимает пустые поля без значений

**Предусловия:** Перейти к онлайн-тренажёру по ссылке https://playground.learnqa.ru/puzzle/triangle

**Шаги:**
1. Не заполнять все поля формы, нажать кнопку "ПОКАЗАТЬ"
2. Не заполнять только поле A, нажать кнопку "ПОКАЗАТЬ"
3. Не заполнять только поле B, нажать кнопку "ПОКАЗАТЬ"
4. Не заполнять только поле C, нажать кнопку "ПОКАЗАТЬ"

**Ожидаемый результат:** Во всех случаях появляется сообщение об ошибке с просьбой заполнить все поля

**Примечание:** [Баг #5](./bug-reports.md#баг-5-форма-ввода-значений-сторон-треугольника-не-валидирует-поле-c) — шаг 4 фактически завершается иначе

## TC3: Double

**Summary:** Ввод дробных числовых значений с разделителем-точкой (.) или запятой (,)

**Предусловия:** Перейти к онлайн-тренажёру по ссылке https://playground.learnqa.ru/puzzle/triangle

**Тестовые данные:**
1. Любые дробные числа с точкой (.), например: 5.5
2. Любые дробные числа с запятой (,), например: 5,5

**Шаги:**
1. Ввести тестовые данные (1) в поле А, остальные поля заполнить любыми числами от 1 до 99999999, нажать кнопку "ПОКАЗАТЬ"
2. Ввести тестовые данные (2) в поле А, остальные поля заполнить любыми числами от 1 до 99999999, нажать кнопку "ПОКАЗАТЬ"
3. Ввести тестовые данные (1) в поле В, остальные поля заполнить любыми числами от 1 до 99999999, нажать кнопку "ПОКАЗАТЬ"
4. Ввести тестовые данные (2) в поле В, остальные поля заполнить любыми числами от 1 до 99999999, нажать кнопку "ПОКАЗАТЬ"
5. Ввести тестовые данные (1) в поле С, остальные поля заполнить любыми числами от 1 до 99999999, нажать кнопку "ПОКАЗАТЬ"
6. Ввести тестовые данные (2) в поле С, остальные поля заполнить любыми числами от 1 до 99999999, нажать кнопку "ПОКАЗАТЬ"

**Ожидаемый результат:** Программа принимает значения и определяет тип треугольника или появляется сообщение об ошибке ("Одна сторона больше суммы двух других или равна ей.")

**Примечание:** [Баг #3](./bug-reports.md#баг-3-форма-для-ввода-значений-неправильно-работает-с-нецелыми-числами)

## TC9: Special characters

**Summary:** Ввод специальных символов в поля формы ввода значений сторон треугольника

**Предусловия:** Перейти к онлайн-тренажёру по ссылке https://playground.learnqa.ru/puzzle/triangle

**Тестовые данные:**
1. Базовая пунктуация: `! @ # % ^ & * ( ) - + = _ { } [ ] : ; " ' \ ~ / |`
2. Символы валют: `₽ $ € £ ¥`
3. Математические символы: `± ÷ ≠ ∞ √ π °`
4. Типографские знаки: `— « » №`
5. Стрелки: `← → ↑ ↓ ↔ ➔ ⇒`
6. Пиктограммы, эмодзи-подобные символы: `❄ ✓ ✕`

**Шаги — поле A:**
1. Ввести в поле А любой символ из категории 1, остальные поля заполнить любыми целыми числами от 1 до 99999999, нажать "ПОКАЗАТЬ"
2. Категория 2 → поле А, остальные поля заполнены, нажать "ПОКАЗАТЬ"
3. Категория 3 → поле А, остальные поля заполнены, нажать "ПОКАЗАТЬ"
4. Категория 4 → поле А, остальные поля заполнены, нажать "ПОКАЗАТЬ"
5. Категория 5 → поле А, остальные поля заполнены, нажать "ПОКАЗАТЬ"
6. Категория 6 → поле А, остальные поля заполнены, нажать "ПОКАЗАТЬ"

**Шаги — поле B:**
7-12. Аналогично шагам 1-6, но символ вводится в поле B

**Шаги — поле C:**
13-18. Аналогично шагам 1-6, но символ вводится в поле C

**Ожидаемый результат:** В любом случае должно появиться сообщение об ошибке ("Это НЕ треугольник.")

**Примечание:** Спецсимвол базовой пунктуации "?" вынесен в отдельный баг — [Баг #1](./bug-reports.md#баг-1-отсутствие-оповещения-об-ошибке-при-вводе-символа-)

**Summary:** В каждое поле формы ввода значений можно ввести целые числа от 1

**Предусловия:** Перейти к онлайн-тренажёру по ссылке https://playground.learnqa.ru/puzzle/triangle

**Тестовые данные:** 0, 1, 2

**Шаги и ожидаемые результаты (по полю A, B, C):**

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Ввести 0 в поле А, остальные поля — любые числа от 1 до 99999999, нажать "ПОКАЗАТЬ" | Сообщение, что треугольник не существует / все значения должны быть больше 0 |
| 2 | Ввести 1 в поле А, остальные заполнены, нажать "ПОКАЗАТЬ" | Сообщение о типе треугольника или "Одна сторона больше суммы двух других или равна ей." |
| 3 | Ввести 2 в поле А, остальные заполнены, нажать "ПОКАЗАТЬ" | Сообщение о типе треугольника или та же ошибка |
| 4-6 | Аналогично шагам 1-3, но для поля B | Аналогично |
| 7-9 | Аналогично шагам 1-3, но для поля C | Аналогично |

## TC14: Zero

**Summary:** Если значение хотя бы одной из сторон треугольника равно нулю, то такого треугольника не существует

**Предусловия:** Перейти к онлайн-тренажёру по ссылке https://playground.learnqa.ru/puzzle/triangle

**Тестовые данные:** 0

**Шаги:**
1. Ввести 0 в любое одно из полей формы, остальные поля заполнить любыми числами от 1 до 99999999, нажать "ПОКАЗАТЬ"
2. Ввести 0 в любые два поля формы, третье заполнить любым числом от 1 до 99999999, нажать "ПОКАЗАТЬ"
3. Ввести 0 во все поля формы, нажать "ПОКАЗАТЬ"

**Ожидаемый результат:** Во всех случаях должно появляться сообщение о том, что такой треугольник не существует или подобное сообщение об ошибке, аналогичное реакции системы на другие невалидные значения

**Примечание:** [Баг #4](./bug-reports.md#баг-4-программа-определяет-треугольник-с-значениями-сторон-0-как-равносторонний) — шаг 3 фактически завершается иначе
